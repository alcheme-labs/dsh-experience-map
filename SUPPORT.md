# Support

Use GitHub issues after the public repository opens for reproducible bugs, compatibility reports, and focused feature requests. Include the plugin version or commit, supported Node version, DeepSeek Harness version, profile type, expected behavior, actual behavior, and a minimal de-identified reproduction.

Do not include credentials, raw Session logs, local databases, user identifiers, or private model content. Security reports belong in the private channel described in [SECURITY.md](SECURITY.md).

The current pre-release supports DeepSeek Harness `0.1.5-rc.2`. Other Harness versions are unverified unless the compatibility table is updated with installed evidence.
